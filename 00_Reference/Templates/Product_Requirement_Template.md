# 产品开发前需求确认表

AI收到新产品需求后，先读取本表，列出“已知、缺失、与当前工作无关”三类；将影响电气与功能的缺失项一次性用中文询问用户。不能猜电池体系、串数、输入电压、负载电流或保护阈值。可继续不依赖这些条件的资料检查和工程准备。

| 项目 | 必须确认的内容 | 用户答案/证据 |
|---|---|---|
| 产品和芯片 | 产品用途；准确芯片型号、封装；是否已有原理图、BOM、旧程序 | 待填写 |
| 供电 | 电池化学体系、型号、串并数、容量；或适配器额定电压/允许范围；是否稳压、USB输入 | 待填写 |
| 负载 | 电机/风扇/灯/发热器类型，额定电压电流、启动/堵转电流；驱动电路、有效电平、PWM允许频率 | 待填写 |
| 按键 | 数量、接法、极性、短按/长按时长、松手动作、连按/组合键、上电持键规则 | 待填写 |
| 指示灯 | 数量、类型/驱动电流与限流、极性、各状态亮灭/闪烁/呼吸、故障优先级 | 待填写 |
| 定时与关机 | 是否需要自动关机、触发条件、时间、操作是否重置计时、恢复策略；不能把无按键等同误操作 | 待填写 |
| 充电 | 充电芯片型号，插入/充电中/充满信号接法、极性与电平；边充边用规则、拔出行为 | 待填写 |
| 电压检测 | ADC参考源、分压电阻、采样脚、最大输入、电源变化范围、校准方式 | 待填写 |
| 低电保护 | 预警/关机/恢复阈值与迟滞、持续确认时间、恢复是否必须重新按键、LVR选择 | 待填写 |
| 电流/堵转 | 采样电阻/放大器、ADC量程、过流阈值和确认时间、启动屏蔽、安全硬件保护与故障复位规则 | 待填写 |
| 低功耗 | 运行/待机/休眠电流目标，唤醒来源与可靠性目标、测量条件、外部器件断电策略 | 待填写 |
| 引脚 | 完整原理图分配、复用冲突、烧录接口、复位脚、未用引脚、GPIO对外部断电器件的连接 | 待填写 |
| 时钟与精度 | IHRC/晶振、2T/4T、计时误差容许值、PWM和ADC对时钟的要求 | 待填写 |
| 交付与验收 | 工程/固件、版本号、工程师联系人、开发板/烧录器、实板清单与未完成项 | 待填写 |

确认后将本表复制为项目的 `Product_Requirements.md`，记录来源和明确假设。芯片没有Validated母版时先走Add-Chip接入，不能拿其它芯片配置代替。未确定的硬件参数不得通过占位常量默认为已验收。
