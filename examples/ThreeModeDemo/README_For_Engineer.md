# 三档灯与按键休眠样板交接

芯片：NY8B062D。参考供电：稳定3.0V，时钟I_HRC 4MHz、4T。工程来自官方 `Sleep_Wakeup` 完整工程，保留真实 `.naprj` / `.NySln` / `.cb` 格式，Makefile由NYIDE官方模板填入参数生成。

## 文件与使用

- 打开 `ThreeModeDemo.NySln` 或 `ThreeModeDemo.naprj` 可查看工程。
- 根目录双击 `Build_Demo.cmd` 可重新编译；脚本为当前进程配置工具路径。
- 烧录输入为 `ThreeModeDemo.bin`，是九齐RIFF容器，包含程序、配置和校验信息；不要按普通裸字节文件长度推算ROM占用。
- `build.log` 为真实工具命令和结果；`Build_Verification.json` 为资源、文件完整性与哈希记录；`Configuration_Readback.json` 为配置字通过九齐库解码读回的结果。
- `Modules/` 保存本项目实际使用的积木副本；以后修改公共积木不会悄悄改变本项目固件。

## 引脚与有效电平

| 引脚 | 功能 | 有效电平/连接 | 休眠状态 |
|---|---|---|---|
| PA0 | 按键与状态变化唤醒 | 按键接GND；内部上拉；低电平按下 | 输入，保留该脚上拉和唤醒 |
| PB0 | 一档灯 | 低亮；VDD→限流电阻→LED→PB0 | 高电平熄灭 |
| PB1 | 二档灯 | 低亮；同上 | 高电平熄灭 |
| PB2 | 三档灯 | 低亮；同上；PWM2保持关闭 | 高电平熄灭 |
| PA5 | 外部复位RSTb/烧录VPP | 本样板保留复位；由工程师设计外部上拉及烧录接口 | 保留复位，不把它当普通输出 |
| PA1/2/3/4/6/7、PB3/4/5 | 本样板未使用 | 不连接外部驱动信号；PA2/3/4兼顾烧录接口 | 稳定低输出；接入实际电路时必须重审 |

建议用SOP16参考板，按所用封装的数据手册引脚图接线，不能把PA/PB编号当成封装脚号。每颗LED必须有限流电阻，芯片近端布置去耦电容。上电初始化顺序已在源码/指令清单中确认：先PORTA/PORTB锁存安全电平，再写IOSTA/IOSTB。

## 逻辑状态

上电默认关机，稳定松手约30ms后进入SLEEP。上电按住按键时保持关机，松手确认后才接受新按键。

每次按下连续3次采样确认，只触发一次：**关机→一档（仅PB0亮）→二档（仅PB1亮）→三档（仅PB2亮）→关机（全灭）**。关机动作先熄灯，等按键稳定松开后休眠。关机时下一次按键直接唤醒并在消抖后进入一档，不需要再按第二次。长按不连续换档。

有任意有效按下即清零无操作计时。开机后连续300秒无新按下，自动关机；若超时当下仍按住按键，先熄灯，等松手后休眠。长按/短按事件由积木提供，本产品只使用PRESS事件换档。

休眠前仅保留PA0唤醒和上拉；关闭WDT避免周期唤醒，保留LVR。先 `DISI()`，开启PA0状态变化源，重读端口、清标志并复核按键电平，再执行 `SLEEP()`；唤醒后不进ISR，继续下一条指令并清标志、恢复WDT及Timer1。睡眠入口附近的按键边沿与电气干扰仍须实板边界验证。

## 定时器计算

1. I_HRC=4,000,000Hz，指令时钟选择4T，FINST=1,000,000Hz，每指令时钟1μs。
2. Timer1预分频16：`T1CR2=0x03`，每计数16μs。
3. 自动重载值624=`0x270`：`TMRH[5:4]=2`、`TMR1=0x70`。从624递减到0再下溢，共625个计数。
4. 中断周期 `(624+1)×16/1,000,000=0.010s`，纯硬件自动重载，避免ISR软件重载引入累计偏差。
5. 3次连续采样消抖，按下和松开均需确认；随边沿相位，通常约20–30ms。长按阈值为确认后100个10ms周期，抖动期间不累加。
6. 100tick=1秒，60秒=1分钟，5分钟=300秒，共30,000tick；计数拆成8位变量，无32位计算。

时间准确度受实际IHRC误差、电压与温度影响；300秒是标称计时，不能声称晶振级精度。ISR仅清Timer1标志并累加待处理tick，不调用子函数。共享变量为volatile，主循环以短临界区取出tick。

## NYIDE Configuration（配置字）

以下值已写入 `.cb` 并通过九齐官方库读回，不只是一份勾选建议。打开NYIDE Configuration时应核对：

| 项目 | 本样板值 | 说明 |
|---|---|---|
| High Oscillation | I_HRC、4MHz | 改频率后必须同步重算Timer1 |
| Instruction Clock | 4T（Clock4） | 不要误选2T，否则计时减半 |
| Low Oscillation | I_LRC | SLEEP中会停止 |
| Power On Clock | High | 上电按4MHz运行 |
| Watchdog | Enable / Register Control | 超时事件Reset，时基250ms；主循环CLRWDT；睡眠前软件关，唤醒后开 |
| LVR Setting | Register Control | 源码始终保留LVREN=1 |
| LVR Voltage | 2.4V | 本样板按3V参考供电；实际电源、电池体系和最低可靠电压须另定，不能照抄给所有产品 |
| PA5 | Reset（RSTb） | 本需求未使用PA5，因此保留复位；只有原理图明确需要该IO且有替代复位安排时才改普通IO |
| PA0/1/2/3 | GPIO，关闭比较器专用输入选择 | ADC与比较器在源码中关闭，PA0用于数字按键 |
| PA7 | GPIO | 不输出指令时钟 |
| Output Port Read | FromRegister | 采用锁存器读值；灯输出整体写入，避免读改写影响其它脚 |
| POR Startup | 18ms | 与参考供电方案配合 |

## 验证结果与边界

真实编译链：NYIDE安装目录的make.exe + 基地内NYC_NY8 2.10/NYASM 2.80。已完成0 Errors、0 Warnings和有效 `.bin` 输出。当前程序352/2048指令字；全局变量13字节，链接后的RAM总分配23/128字节（含临时变量与ISR保存），小于89字节预算。具体以随工程最新JSON与map为准。

已对链接后的指令清单进行有限指令模型行为验证，覆盖上电长按、消抖、松手防连跳、档位循环、唤醒、短/长按事件和300秒计时。这不是九齐官方仿真器，也不是实物测试；模型向Timer1注入中断标志，不建模振荡器/模拟电气行为。

工程师实板需确认：烧录器识别NY8B062D和配置字、各灯/按键极性、上电无闪灯、第四次按键松开后入睡、休眠电流与按键重复唤醒、约5分钟自动关机、供电跌落时LVR/WDT复位表现。尚未连接开发板或烧录器，因此本交付为编译通过的参考样板，未宣称实板或量产验收。
